How the real thing works

On the live site the same steps run on the server, with an extra layer protecting the key.

01 · ENCRYPT

AES-256-GCM

Every image gets its own random key. The stored file is unreadable ciphertext.

02 · WRAP

RSA-protected key

That key is locked with the server's RSA key before it's saved, so a database leak alone reveals nothing.

03 · SHARE

One-time share key

You get a secret shown once. Only its hash is stored — like a password.

04 · UNLOCK

Paste & open

The recipient pastes the key. If it matches, the image is decrypted and checked against its fingerprint.

Worth knowing: anyone who holds the key can open the image — it works like a password-protected link, not like sharing with a specific person's account. Keep keys private, and note that a lost key can't be recovered.
